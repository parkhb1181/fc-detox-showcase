# FC Detox · 코드 발췌

FC 온라인 확률형 상품을 구매 전에 미리 돌려보는 웹 시뮬레이터입니다.
혼자 기획·개발·운영하고 있고, 광고비 없이 10주 동안 누적 방문 61,169회, 9월 하루 평균 1,040명을 기록했습니다.

- 서비스: https://fcdetox.com
- 스택: Next.js (App Router) · Vercel · GA4 · Microsoft Clarity · Claude Code
- 기간: 2026.07 배포, 운영 중

원본 레포는 운영 중인 서비스라 비공개입니다. 여기에는 **문제를 어떻게 풀었는지 설명할 수 있는 부분만** 발췌했습니다.
면접에서 원본 화면 공유가 필요하면 보여드릴 수 있습니다.

## 지표

| 지표 | 값 | 출처 |

| 재방문율 | 34% | GA4 사용자 기준 |
| 참여 시간 | 12분 12초 | GA4 |
| 이탈률 | 18% | Vercel Analytics |
| 검색 유입 비중 | 35.6% | GA4 사용자 기준 |

## 일하는 방식

- 구현은 Claude Code로 빠르게 하고, 막아야 할 것을 먼저 적은 뒤 배포 전 검사로 걸러냅니다(사례 5). **왜 그렇게 했는지**와 실측값·날짜는 코드에 남깁니다.
  같은 실수가 다른 화면에서 다시 터지지 않게, 호출부마다 고치기보다 훅이나 스크립트에서 규칙으로 막는 편입니다.
- 숫자는 값보다 산출 방식을 먼저 봅니다. 사례 2와 3이 그 기록입니다.

## 발췌 범위

- 설명에 필요한 부분만 잘라 왔고, 주석은 읽기 쉽게 일부 다듬었습니다. 로직은 원본 그대로입니다.
- 게임 데이터, 이미지, 수집 스크립트, API 키, 외부 경로는 넣지 않았습니다.
